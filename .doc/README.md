# Documentation Alfred

Les nouveaux documents projet sont centralisés ici. Les README existants à la racine et dans front/ restent en place, ainsi que les instructions AGENTS.md.

- [Catalogue visuel](design/README.md) et [guidelines](design/guidelines.md).
- `features/` : spécifications, user stories, critères et tâches, créés sur demande après clarification du besoin.
- `architecture/` : décisions techniques, comparaisons, diagrammes et ADR, créés sur demande.

Les deux derniers dossiers seront créés au premier document utile. Le [suivi pédagogique](../.agents/learning/progress.md) et la [roadmap](../.agents/learning/roadmap.md) restent dans .agents/learning/ : ce sont des données de mentorat.

Parcours : besoin validé → conception → maquette sélectionnée → découpage frontend → implémentation par le développeur → tests → revue. Aucun passage automatique à l'implémentation.
